Python Web Scraping Modular Architecture

LeBonCoin Ad Monitoring System

LeBonCoin is the most popular classified ads website in France, with thousands of ads posted every day.
Among these ads, some prices are very attractive. But market laws obviously make them disappear quickly.
If only we had a way to automate the search for these ads and be notified as soon as they are published, almost in real-time.

The goal of this project was to create an automated system capable of continuously monitoring new smartphone ads and notifying me only of real good deals, by automatically filtering out defective devices.

Project Overview

Overview: data list and project scripts

This project took several months of development, with many iterations to optimize performance and reliability. The final architecture combines several Python modules working together to fully automate monitoring.

Technical Details

I will elaborate on some interesting technical aspects of this project.

Retrieving Cities and Postal Codes

Retrieving city name and postal code by scraping

I had to find a way to know the distance of each ad. To do this, I retrieve by scraping the city name and postal code directly from the LeBonCoin ad page.

At first, I wanted to use trigonometry to get the distance directly from my position, but I found an API on the internet that gives the distance in kilometers from longitude/latitude coordinates.

Geographic Database

French cities database (government source)

So I took a .sql database that gives precisely the longitude/latitude coordinates of all French cities. This database comes from the French government website in open access.

We can exploit this SQL file to extract and process the data. I then transformed it into a .txt file to be able to process it more easily with my Python scripts.

I Get a Great Function!

Final geographic distance calculation function

The result of all this work is a function that takes the postal code and city name as parameters, and returns the road distance in kilometers from my position. This function combines all the retrieved data (government database, distance API) to provide accurate and usable information.

Defective Device Detection and Web Scraping

Defective device detection functions and regular expressions

Web Scraping and Regular Expressions

Web scraping consists of automatically extracting data from web pages. In my case, I had to retrieve LeBonCoin ad information: title, price, description, location, etc.

Regular expressions (regex) are essential for this project. They allow to:

  • Detect defective keywords: patterns like "broken", "cracked", "not working", "cracked screen", "for parts"
  • Extract models: precisely identify "iPhone 13", "Galaxy S24", etc. in the title
  • Validate prices: ensure the price format is consistent (e.g., "250€" or "250 euros")
  • Parse descriptions: search for additional information hidden in the text

Regex allows me to create very precise patterns to avoid false positives and ensure reliable detection of filtering criteria.

User-Friendly Interface

Telegram commands for user-friendly use

I also added Telegram commands to make the system more user-friendly. Rather than having to modify the code each time, I can now:

  • Modify price thresholds directly via Telegram
  • Consult real-time statistics
  • Restart or stop monitoring remotely
  • Receive operational reports

Final Result

The system works perfectly! It automatically monitors LeBonCoin 24/7, analyzes new ads and only notifies me of real good deals. No more hours spent manually scrolling through ads!

The modular architecture makes it easy to add new criteria or adapt the system to other sites. This project allowed me to completely automate a time-consuming task while developing my skills in Python and web scraping.
