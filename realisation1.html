Description du projet

Ce site est ma vitrine numérique. Je l’ai créé pour garder une trace de mes projets, partager mon domaine de compétences et présenter concrètement ce que je fais. Il me permet aussi d’expliquer facilement mon travail à tout moment, que ce soit pour un contact professionnel, un collaborateur ou simplement pour garder une continuité dans ce que je construis. C’est un espace évolutif, au service de mes idées et de mes réalisations.

Fonctionnalités clés

  • Fonctionnalité 1 : Une liste de mes réalisations.
  • Fonctionnalité 2 : Une liste de mes projets en cours.
  • Fonctionnalité 3 : Une liste de projets un peu plus professionnels.
  • Fonctionnalité 4 : Une page de contact serait bien aussi.

Détails techniques

Pas beaucoup de CSS pour le moment. J’ai structuré les différentes pages avec des balises classiques <header>, <nav>, <main>, etc. pour garder un rendu clair et fonctionnel, sans framework ni librairie externe.

J’ai organisé le projet en plusieurs fichiers `.html`, chacun correspondant à une section du site (accueil, réalisations, projets, etc.). Les liens entre les pages se font simplement via des balises <a>, et l’arborescence est pensée pour rester lisible et facile à maintenir. Les images sont stockées localement dans un dossier `images/` et intégrées avec des chemins relatifs via des balises <img>.

Le site est versionné avec Git et hébergé sur GitHub, ce qui me permet de garder une trace propre des modifications. Pour le déploiement, j’utilise Netlify, qui récupère automatiquement le dépôt GitHub et met à jour le site à chaque push. Ce setup m’a permis d’apprendre à configurer un dépôt distant, créer un site statique sur Netlify, et gérer des mises en production continues sans prise de tête.

C’est un projet full-HTML/CSS pour le moment, sans JavaScript ni backend, mais qui pose les bases d’un site perso évolutif. Le JS viendra peut-être plus tard (ou pas, selon mes besoins), une fois que la structure HTML sera bien en place.

Résultats

Le résultat est tel que vous le voyez : un site web simple, structuré en plusieurs pages. Il a été conçu pour être fonctionnel, lisible et accessible à tout moment. Ce site n’a pas vocation à être figé — je pense qu’il ne sera jamais vraiment terminé. Il continuera d’évoluer avec mes projets, mes idées et mes besoins du moment.
