Project Description

This site is my digital showcase. I created it to keep track of my projects, share my area of expertise, and concretely present what I do. It also allows me to easily explain my work at any time, whether for a professional contact, a collaborator, or simply to maintain continuity in what I build. It's an evolving space, serving my ideas and achievements.

Key Features

  • Feature 1: A list of my achievements.
  • Feature 2: A list of my ongoing projects.
  • Feature 3: A list of more professional projects.
  • Feature 4: A contact page would be nice too.

Technical Details

Not much CSS for now. I structured the different pages with classic <header>, <nav>, <main>, etc. tags to keep a clear and functional rendering, without any external framework or library.

I organized the project into several `.html` files, each corresponding to a section of the site (home, achievements, projects, etc.). Links between pages are done simply via <a> tags, and the structure is designed to remain readable and easy to maintain. Images are stored locally in an `images/` folder and integrated with relative paths via <img> tags.

The site is versioned with Git and hosted on GitHub, which allows me to keep a clean track of changes. For deployment, I use Netlify, which automatically retrieves the GitHub repository and updates the site with each push. This setup allowed me to learn how to configure a remote repository, create a static site on Netlify, and manage continuous production updates without hassle.

It's a full-HTML/CSS project for now, without JavaScript or backend, but it lays the foundation for an evolving personal site. JavaScript might come later (or not, depending on my needs), once the HTML structure is well established.

Results

The result is as you see it: a simple website, structured in several pages. It was designed to be functional, readable, and accessible at any time. This site is not meant to be static — I think it will never really be finished. It will continue to evolve with my projects, ideas, and current needs.
