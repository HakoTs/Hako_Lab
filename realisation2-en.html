Automatic Peanut Dispenser

Project made with my little brother: a fully automatic peanut dispenser based on Arduino Mega. This system detects coin insertion using an optical sensor and automatically distributes one peanut via a dual servo motor mechanism.

Project Evolution

Initial phase: first tests and prototyping
Development: component assembly

Working Principle

Coin Detection

Explanatory diagram: LED + photoresistor for detection

The heart of the detection system relies on a simple but effective principle: an LED emits a constant light beam towards a photoresistor.

When a coin passes between the two, it cuts the beam, which drops the brightness received by the photoresistor. The Arduino detects this variation and triggers the dispensing process.

The rail perfectly guides the coin so it properly cuts the light beam.

Distribution Mechanism

Once the coin is detected, the real challenge begins: dispensing exactly one peanut, no more, no less. For this, I designed a dual-door system:


  1. Servomotor 1 opens → peanuts descend
  2. One peanut falls into the intermediate chamber
  3. Servomotor 1 closes (blocks other peanuts)
  4. Servomotor 2 opens → the peanut falls
  5. Servomotor 2 closes → return to initial state


This two-step sequence prevents multiple peanuts from falling at once. In theory... In practice, sometimes two peanuts sneak through, but that's part of the project's handmade charm!

Components Used

Hardware list

  • Arduino Mega: system brain, manages all sensors and actuators
  • 2 Servomotors: control opening/closing of distribution doors
  • 1 LED: light source for detection
  • 1 Photoresistor: light sensor to detect obstruction
  • 2-line LCD display: visual feedback on system status
  • Mechanical structure: tube, rails, supports (homemade!)

Challenges and Solutions

Key development points

  • Photoresistor calibration: finding the right detection threshold according to ambient lighting
  • Servomotor timing: perfectly synchronizing opening/closing to avoid jams
  • Handmade mechanics: adjusting rail and tube dimensions for smooth operation
  • Error handling: what to do if a peanut gets stuck?
  • User interface: clear display on LCD screen ("Insert coin", "Dispensing...", etc.)

Final Result

The system in action: from coin to peanut!

The dispenser works as expected! You insert a coin, the system detects it, and boom, a peanut falls. Sometimes two, but that's an unexpected bonus. 😉

The code was fairly easy; the real goal was mainly educational and fun. I introduced my little brother to programming by showing him that code isn't magic: how a simple sensor detects a coin, how a motor knows when to turn, and how everything works together. We talked about logic, signals, and the magic (actually very concrete) that transforms an idea into something tangible.

Result: he now has his own peanut dispenser... and he knows how it works from the inside.

Collaboration with my little brother required us to divide tasks: him on mechanics and crafting, me on programming and electronics. Real teamwork!

Possible Improvements

  • Improve mechanics to guarantee a single peanut each time
